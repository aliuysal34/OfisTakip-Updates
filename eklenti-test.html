Ofis Takip Login Helper – test page for reviewers

The extension normally works together with the Ofis Takip desktop application, which runs on each accounting firm's own computer and stores its clients' login details. This page simulates that application so the extension can be tested without installing it and without any real account: it sends made-up sample data to the extension, exactly as the application's "Kuruma git" (go to institution) button does.

Checking for the extension…

Steps
  1. Install the extension and open this page (reload it once after installing).
  2. Click one of the buttons below. The extension opens the official login page in a new tab.
  3. On that page the extension fills the user name and password fields with the sample values below and places the cursor in the security-code (CAPTCHA) field. The extension never solves the security code; the user types it.
  4. Because the sample data is fake, the official site will reject a login attempt. This is expected: the feature being tested is the form filling. Real logins require real Turkish taxpayer credentials, which cannot be shared.

Sample data sent: user 11111111110, password Test.Ornek.1, workplace password Ornek2, extra code 1. Nothing is sent to any server; this page has no network code.
